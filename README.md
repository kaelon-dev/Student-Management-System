# Student Management System

An open-source management application featuring a Java console backend and a responsive modern web interface.

## Repository Structure

- \student.java\ - Java console application providing data encapsulation, validation, and full CRUD operations.
- \Web-Frontend/\ - Modern single-page web frontend with responsive design and light/dark theme support.
- \LICENSE\ - MIT License.

## Features

- **Console Application (Java)**:
  - Robust student model with ID, Name, Age, GPA, Major, and Email.
  - Safe state encapsulation and input boundary checking.
  - Complete record management (Add, View, Search, Update, Delete).

- **Web Frontend**:
  - Clean glassmorphism styling and dark/light mode toggle.
  - Interactive student records table with real-time GPA progress bars and summary metrics.
  - Add and edit record modals with client-side form validation.

## Getting Started

### Running the Java Console App
Compile and execute the program with Java:
\\\ash
javac student.java
java Main
\\\

### Running the Web Frontend
Simply open \Web-Frontend/index.html\ in any modern web browser.
